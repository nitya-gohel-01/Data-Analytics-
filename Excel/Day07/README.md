# 🛒 E-Commerce Sales Analytics & Data Modeling -- Microsoft Excel

An interactive **E-Commerce Sales Analytics Dashboard** created using
**Microsoft Excel** as part of my Data Analytics learning journey at
**Adani Skill Development Centre**.

This project focuses on analyzing a real-world-style e-commerce sales
dataset containing **5,000+ records** and transforming the raw data into
meaningful business insights using **Pivot Tables, Pivot Charts,
Slicers, KPIs, and dashboard design**.

## 🎯 Project Objective

The objective of this project was to analyze e-commerce sales data and
build an interactive dashboard that provides a clear overview of
revenue, quantity, products, regions, payment methods, and time-based
performance.

The project also provided practical experience in organizing and
analyzing business data for reporting and decision-making.

------------------------------------------------------------------------

## 📁 Dataset Overview

The dataset contains **5,000+ e-commerce sales records** with fields
such as:

-   Order ID
-   Order Date
-   Product Category
-   Region
-   Quantity
-   Unit Price
-   Discount
-   Payment Method
-   Delivery Days
-   Customer Rating

These fields were used to perform sales, product, regional,
payment-method, and time-based analysis.

## 📈 Dashboard Analysis

### 💰 Total Revenue by Payment Method

A chart comparing revenue generated through different payment methods to
understand which payment channels contribute the most to overall
revenue.

### 🏷️ Total Revenue by Category

A category-level analysis showing how different product categories
contribute to total revenue.

### 🌎 Total Revenue by Region

A regional comparison that helps identify regions with stronger sales
performance.

### 📅 Total Revenue by Quarter

A quarterly analysis used to understand changes in revenue throughout
the year.

### 📦 Total Quantity of Products

A product-level quantity analysis showing which products have higher
sales volume.

### 📆 Total Revenue by Year

A year-wise trend analysis that helps compare revenue performance across
different years.

Year-wise Revenue Trends**

This structure allows users to move from a high-level overview to
detailed sales analysis.
